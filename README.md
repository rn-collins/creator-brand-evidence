# Evidence·Studio — Evidence-based brand & creator strategy for trust-sensitive markets

Evidence-based brand and creator strategy for trust-sensitive markets: health, legal, wellness. Governance and disclosure, not guesswork. Built by RN Collins.

**Live:** https://creator-brand-evidence.vercel.app

## Repository contents

Thirteen static pages — `index.html`, `about.html`, `method.html`, `services.html`, `creator-brand-evidence-audit.html`, `audit-deliverables.html`, `governance-brand-systems.html`, `partnership-strategy-sprint.html`, `thought-leader-system.html`, `retainer.html`, `curriculum-dashboard.html`, `insights.html`, `contact.html` — plus `assets/`, `vercel.json`, and `creator-lurker/`, a scaffold for the evidence-collection service (schema, prompts, and docker-compose; no collected data is committed).

## Local development

Static site. No build step — open `index.html`, or serve the directory with any static file server.

## Deployment

Deployed on Vercel from `main`. Every push to `main` triggers a production build.
